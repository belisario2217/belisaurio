# Organización de la plataforma

El menú presenta las áreas en este orden. Cada usuario ve únicamente los accesos que sus permisos ya permiten.

| Área | Secciones |
| --- | --- |
| Mi espacio | Inicio y, para alumnos, avance, calificaciones, pagos y credencial |
| Gestión académica | Alumnos, grupos, planes y calificaciones |
| Servicios escolares | Documentos, credenciales y asistente de archivos |
| Finanzas | Balance, cobros, colegiaturas y nómina |
| Información y comunidad | Mensajes, reportes y analíticas |
| Configuración | Catálogos, usuarios y configuración institucional |

Inicio agrupa los accesos por tarea y muestra los indicadores disponibles para cada perfil. El portal del alumno da prioridad al avance y conserva los pagos y las calificaciones en páginas independientes. Si la contraseña sigue siendo temporal, el aviso de cambio permanece al principio.

La interfaz combina bordes translúcidos, fondos pastel y acentos de color por área. El desenfoque se limita a navegación, cabecera y diálogos. Las animaciones CSS y las gráficas respetan la preferencia de movimiento reducido del dispositivo. No se agregaron librerías ni consultas al servidor para los efectos visuales.

Las rutas, los permisos, los datos y los formatos PDF/Excel se conservan. Asistencia y Folios siguen retirados.
